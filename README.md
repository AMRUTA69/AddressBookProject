# Address Book Application (Java)

A complete console-based Address Book application written in Java. It allows users to add, view, and delete contacts, and saves the data to a file so it persists between sessions.

## ✨ Features

- ✅ Add new contacts with Name and Phone number.
- ✅ View all saved contacts.
- ✅ Delete contacts securely.
- ✅ Data persistence using File Handling (`contacts.txt`).
- ✅ Proper exception handling for corrupted files.

## 🛠️ Technologies Used

- **Language:** Java (JDK 21)
- **IDE:** Eclipse
- **Data Structure:** `ArrayList<Contact>`
